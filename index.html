프로젝트 소개 및 특기사항

이 프로젝트는 유니티 엔진과 C#을 활용하여 2개월간 개발한 2D 횡스크롤 액션 게임입니다. 플레이어의 조작감과 타격감을 극대화하는데 초점을 맞추었으며, 객체 지향 프로그래밍(OOP) 원칙을 준수하여 확장성 있는 코드를 작성하려 노력했습니다.

✨ 주요 구현 기능

  • FSM (유한 상태 기계) 패턴: 플레이어 및 적 AI의 상태(Idle, Run, Attack, Die 등)를 효율적으로 관리.
  • 오브젝트 풀링 (Object Pooling): 총알 및 이펙트 생성 시 발생하는 메모리 할당을 최소화.

핵심 코드 리뷰

PlayerController.cs 
using UnityEngine;
using System;

public class PlayerController : MonoBehaviour
{
    [SerializeField] private float moveSpeed = 5f;
    public event Action OnPlayerDeath;

    private StateMachine stateMachine;

    private void Awake()
    {
        stateMachine = new StateMachine();
        stateMachine.ChangeState(new PlayerIdleState(this));
    }

    private void Update()
    {
        stateMachine.Update();
    }
}
